## Метки

Каждый пункт описывает, что это такое. Метки рядом помогают выбрать: официальный, когда это от организации, которая задаёт стандарт; открытый код, когда код опубликован; бесплатно или платно по модели использования; API и SDK по способу интеграции. Пункты с меткой "от автора" сделаны Ciro Cesar Maciel и соблюдают те же правила, что и все остальные.
