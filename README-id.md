## Label

Setiap item menjelaskan apa itu. Label di sebelahnya membantu memilih: resmi jika berasal dari pembuat standar, open source jika kodenya dipublikasikan, gratis atau berbayar menurut model penggunaannya, serta API dan SDK menurut cara integrasinya. Item dengan label "buatan penulis" dibuat oleh Ciro Cesar Maciel dan mengikuti aturan yang sama dengan item lainnya.
