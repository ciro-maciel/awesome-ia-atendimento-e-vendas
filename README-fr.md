## Règles du service client

Ce que le client a le droit d'exiger.

- [Código de Defesa do Consumidor](https://go.mymarketing.click/iavend-codigo-de-defesa-do-consumidor) - Le CDC compilé sur le site du Planalto. `officiel` `gratuit`
- [Decreto do comércio eletrônico](https://go.mymarketing.click/iavend-decreto-do-comercio-eletronico) - Le décret 7.962/2013, avec les règles de ceux qui vendent sur internet. `officiel` `gratuit`
- [Decreto do SAC](https://go.mymarketing.click/iavend-decreto-do-sac) - Le décret 11.034/2022, avec les règles du service client. `officiel` `gratuit`
- [Lei do atendimento prioritário](https://go.mymarketing.click/iavend-lei-do-atendimento-prioritario) - La loi 10.048/2000, sur la priorité d'accès au service. `officiel` `gratuit`
- [Não Me Perturbe](https://go.mymarketing.click/iavend-nao-me-perturbe) - L'inscription pour bloquer les appels de télémarketing des opérateurs et des banques. `gratuit`
- [Prefixo 0303 na Anatel](https://go.mymarketing.click/iavend-prefixo-0303-na-anatel) - La règle qui oblige le télémarketing sortant à appeler avec le préfixe 0303. `officiel` `gratuit`

- [Lei do vendedor](https://go.mymarketing.click/iavend-lei-do-vendedor) - La loi 3.207/1957, sur les vendeurs, voyageurs et pracistas. `officiel` `gratuit`
- [TST: cobrança de metas por WhatsApp](https://go.mymarketing.click/iavend-tst-cobranca-de-metas-por-whatsap) - La décision du TST sur la fixation d'objectifs en dehors des heures de travail. `officiel` `gratuit`

## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand il vient de l'organisme qui définit la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la façon de l'intégrer. Les éléments avec l'étiquette "de l'auteur" sont faits par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
